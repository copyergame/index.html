⬡ Game Copier · v2

1. Press "Open GamesApi" → then go to Inspect → Network tab. Refresh (Ctrl+R).

2. Scroll up and you will find "game". Right click on "game" and hover over copy → select "Copy all as PowerShell" or "PowerShell". Once done go back to this website, paste the code you copied from the gameapi page into the "Game Code" box and then copy the ID of the game you want to copy and paste it into "Game ID" box. Then Click The "Start GameCopier" Button. Wait until the bar finishes loading and the game files will Download.
